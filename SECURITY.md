# Política de segurança

Não publique vulnerabilidades que exponham usuários em uma issue pública.

Envie o relato para `heron@belluzzi.dev` com:

- Descrição e impacto esperado.
- Versão ou commit afetado.
- Passos mínimos para reprodução.
- Possível correção, caso exista.

Não inclua dados reais de terceiros, credenciais ou conteúdo sensível. O
recebimento será confirmado assim que possível e a correção será coordenada
antes da divulgação pública.
